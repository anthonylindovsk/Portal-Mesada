# Modelo de dados A03

## perfis
- nome (string) — "Anthony"
- tipo (string) — "master" ou "junior"
- pinHash (string) — hash do PIN só existe depois do primeiro acesso
- pinDefinido (boolean) — false até o primeiro acesso depois true
- avatarCor (string) — cor de identificação do perfil
## tarefas
- nome (string) — nome da tarefa
- descricao (string) — texto explicando a tarefa, opcional
- valorCentavos (number) — valor em centavos sem decimal
- tipoAtribuicao (string) — "fixa" ou "bonus"
- criancaId (string ou null) — null quando é bônus ainda sem dono
- prazo (Timestamp) — data e hora limite pra concluir
- status (string) — "aberta", "disponivel", "aguardando_aprovacao", "aprovada" ou "perdida"
- tentativas (number) — começa em 0 maximo 3
- motivoRejeicao (string) — o pai escreve quando rejeita
- observacaoCrianca (string) — texto que a crianca escreve ao concluir
- fotoUrl (string) — link da foto no Storage
- dataCriacao (Timestamp) — hora que a tarefa foi criada
- dataAceite (Timestamp) — so em tarefa bonus, quando alguem aceita
- dataConclusao (Timestamp) — hora que a crianca enviou a conclusao
- dataAprovacao (Timestamp) — hora que o pai aprovou
- dataPerda (Timestamp) — hora que virou perdida
- pago (boolean) — true depois que entra num pagamento
- pagamentoId (string) — id do pagamento, se ja foi pagoo

## pagamentos
- criancaId (string) — quem recebeu o pagamento
- valorCentavos (number) — valor total pago, em centavos
- dataPagamento (Timestamp) — hora que o pagamento foi feito
- tarefaId (string) — lista das tarefas que entraram nesse pagamento
- observacao (string) — texto livre, opcional
